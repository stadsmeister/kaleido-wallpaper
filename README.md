# Kaleido Wallpaper

De caleidoscoop uit de Psychedelic Visualizer als live, muziekgestuurde bureaubladachtergrond.

| Map | Platform | Bouwen |
|---|---|---|
| `MacOS/` | macOS 13+ (Swift) | `cd MacOS && ./build.sh` (Xcode Command Line Tools) |
| `Windows/` | Windows 10 2004+ / 11 (C# / .NET 8) | `Windows\build.cmd` (.NET 8 SDK) |

Beide versies gebruiken exact dezelfde `kaleido.html` (`MacOS/Resources/` en `Windows/wwwroot/`) en hebben
dezelfde instellingen. Elke map heeft een eigen README met de details.
